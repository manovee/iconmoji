# Contributing

Thanks for contributing to `iconmoji`.

## Local setup

```bash
npm install
npm run typecheck
npm run build
npm run preview
```

Open `http://127.0.0.1:4173/preview/` to exercise the package locally.

## Pull requests

- Keep changes focused and explain the user-facing impact clearly.
- Update `README.md` when the public API or usage changes.
- Run `npm run typecheck` and `npm run build` before opening a PR.
- Include screenshots or a short recording when the preview surface changes.

## Scope

Good contributions include:

- picker UX improvements
- accessibility fixes
- search quality improvements
- documentation and examples
- performance improvements that do not add heavy runtime dependencies
