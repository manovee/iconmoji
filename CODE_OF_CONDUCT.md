# Code of Conduct

This project expects respectful, constructive collaboration.

## Expected behavior

- Be respectful in code review and issue discussions.
- Assume good intent and focus on the technical problem.
- Give actionable feedback with enough detail to reproduce issues.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language
- Publishing private information without permission
- Repeatedly derailing technical discussions

Project maintainers may edit, hide, or remove contributions that violate these expectations.
